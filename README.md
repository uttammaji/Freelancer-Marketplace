# Freelancing Web Page

A full-stack freelance marketplace where clients can post projects and hire professionals, while freelancers can submit proposals, manage contracts, and receive payments.

## Tech stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Data and services:** MongoDB, Redis, Cloudinary

## Project structure

- `client/` — React web application
- `server/` — Express API and real-time services

## Getting started

Install dependencies in each application directory:

```bash
cd server
npm install
```

```bash
cd client
npm install
```

Configure the server and client environment variables using the provided `.env.example` files. Start the API and frontend from their respective directories:

```bash
npm run dev
```

## Features

- Client and freelancer accounts
- Project listings and proposals
- Contract workspaces and messaging
- Escrow, payments, and payouts
- Reviews, notifications, and admin tools
